# IP_Cam Automated Tests TODO

These are additional automated tests worth adding before the large refactor. The list is ordered from highest to lowest priority for refactoring safety. It intentionally excludes scenarios that are already covered by the current JVM and real-device suite.

Also excluded on purpose:

- real end-to-end OTA update checks/downloads against GitHub Releases, because the current code has no injectable network transport and a stable automated test would become internet-dependent
- the successful `/reboot` path, because a passing test would intentionally restart the device running the suite
